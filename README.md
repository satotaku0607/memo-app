# チームタスク管理

グループメンバーのタスク進捗を、スプレッドシートのような表で管理できる Todo アプリです。
タスクごとにチャットルームがあり、タスクに関するやり取りをその場で残せます。

G's アカデミー 第4回「localStorage・JSON・配列・for文」の課題（メモ帳アプリ）を発展させて作りました。

### メンバー管理
- メンバーの追加・削除
- メンバーを追加すると、タスク一覧にその人のステータス列が自動で増える

### タスク管理（シート風の表）
- 列：No／タスク名／期限／依頼主／メンバーごとのステータス／備考
- ステータスは「未着手・対応中・済・ー」の4種類から選択（色分け表示）
- 表のセルを直接編集でき、変更は自動で保存される
- 期限切れのタスクは日付を赤字で表示
- 全員が「済」または「ー」になったタスクは完了扱い（取り消し線）
- 「完了を隠す」チェックで完了タスクを非表示
- 1件削除／全削除

### タスクごとのチャットルーム
- 各タスクの「💬」ボタンから右側にチャットパネルが開く
- 発言者（メンバー）を選んでメッセージを送信
- 自分の発言は右寄せ・青色で表示
- Enter で送信、Shift + Enter で改行（日本語変換中の Enter では送信しない）
- Esc キーまたは背景クリックで閉じる
- 💬 ボタンにメッセージ件数を表示

## 使い方

1. `index.html` をブラウザで開く
2. 「メンバー」に名前を入力して追加する
3. 「タスク追加」にタスク名・期限・依頼主を入力して追加する
4. 表の中でステータスや備考を更新する
5. 💬 ボタンからタスクごとのチャットを開いて会話する

## 工夫した点

- 授業で作った「1つのキーに配列をまとめて保存する」方法を、メンバー・タスク・チャットの3種類のデータに広げた
- メンバーの人数に合わせて表の列を for 文で組み立てるようにした
- 後から追加される要素にもクリックが効くよう、`$("親要素").on("click", "子要素", ...)` の形でイベントを設定した
- 入力された文字をエスケープしてから表示し、`<script>` などが実行されないようにした
- 日本語入力中の Enter で誤って送信されないようにした

## 制限事項・今後の課題

- localStorage は使っているブラウザの中だけに保存されるため、実際には他の人とデータを共有できない（現在は発言者を切り替えることでグループ利用を再現している）
- 今後、Firebase などのサーバー側の仕組みを使って、複数人でリアルタイムに共有できるようにしたい
- タスクの並び替え（期限順など）や担当者での絞り込みも追加したい
